# diagrams/

Purpose

The diagrams/ directory stores source files for architecture diagrams, UX flows, and export-ready graphics used in documentation and presentations.

What belongs here

- Source diagram files (e.g., draw.io, SVG sources) and export-ready PNG/SVG assets that are lightweight.
- Short READMEs describing diagram provenance, the editing tool used, and any licensing for included assets.

What does not belong here

- Large or proprietary binary assets. Keep diagram sources small and document how to regenerate larger assets.

How to use this folder

- Prefer vector formats (SVG) for export-ready assets and include source files when possible.
- Annotate diagrams with brief provenance notes and the author/maintainer for edits.
