# roadmap/

Purpose

The roadmap/ directory contains project planning artifacts: milestones, timelines, deliverables, and high-level prioritization relevant to the Unified Update Experience Framework.

What belongs here

- High-level milestone descriptions and expected deliverables.
- Roadmap rationale and prioritization notes for research and product work.
- Release planning notes and any public project timelines.

What does not belong here

- Sensitive personnel information or private schedules.

How to use this folder

- Keep roadmap items high-level and time-bounded. Use separate files for major milestones and update them as the project evolves.
- Avoid committing ephemeral meeting notes; instead, summarize decisions and refer to external project trackers when needed.
