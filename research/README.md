# research/

Purpose

The research/ directory is intended for reproducible research artifacts: study protocols, experiment templates, evaluation rubrics, and sanitized, public-ready artifacts that support the project’s findings.

What belongs here

- Study and experiment protocols (pre-registrations, methods descriptions).
- Reproducibility checklists and minimal scripts that show how results were produced.
- Public-ready summaries of findings and analysis READMEs that document data sources and provenance.

What does not belong here

- Private, proprietary, or personally identifying data. Do not commit raw interview transcripts, recordings, or PII.
- Fabricated results or placeholder research outputs.

How to contribute

- When adding an artifact, include a README that documents purpose, provenance, licensing, and a short reproducibility checklist.
- Reference external datasets by stable URLs and include instructions for obtaining access where appropriate.
