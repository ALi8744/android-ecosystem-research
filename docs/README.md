# docs/

Purpose

The docs/ directory stores high-level project documentation intended for readers who want to understand the research methods, design decisions, and reproducibility guidance for the Unified Update Experience Framework.

What belongs here

- Literature reviews, methods documents, and whitepapers.
- Ethics, consent, and IRB-related documentation (public summaries only; do not include raw sensitive data).
- Reproducibility guides and instructions for recreating analyses, figures, or experiments.
- Governance documents that are project-level and long-lived (e.g., CITATION.cff is at repo root; docs may expand with extended citation and archiving guidance).

What does not belong here

- Raw or proprietary datasets (link externally instead).
- Private interview transcripts or recordings.

How to use this folder

- Add a small README with provenance for each major document.
- Keep documents plain-text (Markdown) where possible and include machine-actionable metadata when helpful.
