# references/

Purpose

The references/ directory is a curated bibliography and resource hub for materials relevant to this project: academic papers, standards, vendor documentation, and authoritative external links.

What belongs here

- Machine-readable bibliographies (e.g., BibTeX, Zotero exports), annotated references, and short summaries.
- External standards and policy references (with links and citation metadata).
- Recommended reading lists that inform the framework and design decisions.

What does not belong here

- Full-text copies of works when restricted by copyright. Link to publisher versions or permissible open-access copies instead.

How to use this folder

- Add a short README per subtopic (e.g., standards, vendor docs, academic literature) describing scope and curation criteria.
- Prefer persistent identifiers (DOIs, stable URLs) when citing materials.
