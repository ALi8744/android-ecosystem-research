# images/

Purpose

The images/ directory holds lightweight visual assets, icons, and figures used by the repository documentation and website. These should be small, public-ready, and appropriately licensed.

What belongs here

- Small images and figures that are licensed for public reuse or created by project contributors.
- Thumbnails, icons, and low-resolution assets for documentation.

What does not belong here

- Large datasets of images, proprietary media, or raw photo/video archives.

How to use this folder

- Include a short README describing licensing expectations and attribution requirements for images added to this directory.
- Prefer lightweight, compressed file formats and include source attribution in image captions or nearby READMEs.
